# ProBigA 全系统体验与判断审查 · 2026-09-19

## 结论与产品目标

原系统最主要的问题不是少一张图，而是缺少清楚的看盘顺序，而且一些数字和状态表达了超出证据的确定性。交易后台的批次、权限和运行状态占据首页；行情、研究推断、当前持仓与历史记录混在一起，用户难以回答“市场发生了什么、与我有什么关系、接下来核对什么”。

本次直接实现一个统一工作台，路径为 **市场事实 → 板块线索 → 个股依据 → 自选与持仓 → 事后验证**。交易台保留为独立账本和决策核对页，数据管理放入系统工具；删除重复导航布局和独立雷达旧页面。

参考图片采用了清楚的视觉层级、指标解释与历史验证区，这些组织方式值得借鉴。但图片中的情绪分、Mom/Dad、相似状态收益不能从本系统现有证据直接推导。本次没有照搬或制造这些分数，而是展示真实广度、指数趋势、板块观察及当时留存的判断。

## 问题、方案与已实现行为

| 角度 | 发现的问题 | 最终实现 |
| --- | --- | --- |
| 首页重点 | 先看到后台运行状态，缺少市场全貌与行动路径 | 工作台先展示市场广度和证据时点，给出下一步核对对象，再展开六个信息区；统一导航和六位证券码搜索 |
| 市场判断 | 指数与板块样本混称、缺失补零、旧行情被称实时 | 拆开真实指数和 002/300/301 样本，保留真实零与未知；标记盘中、午间、收盘、过期及历史回退 |
| 图表表达 | 日期不完整、不同量纲混读、用不完整成交直接解释强弱 | 广度与成交额分别绘图，缺口断开，日期与数值可展开；盘中成交明确未完成 |
| 板块观察 | 昨日板块混入今日、热度被误读为资金净流入 | 仅展示与行情同日的行业观察；说明成交额/热度排序含义，不直接给出买入建议 |
| 候选可信度 | 日期、运行批次、候选数量与完成状态可能不一致 | 联合核验上下文和股票池后才给候选数量与研究结论；证据失败不显示为“没有机会” |
| 历史复盘 | 当前自选被误认成历史账户，历史卖出被当成今日操作 | 历史策略保持只读，当前自选明确标注当前快照；历史持仓评估不冒称账户还原 |
| 盈亏与绩效 | 未知被填 0；单笔收益相加、最差交易冒充组合回撤 | 样本统计和组合净值分开；没有净值就不输出组合回撤/夏普；缺报价不伪造 -100% 或 0% 收益 |
| 概率解释 | 规则置信分、先验研究分被写成胜率 | 未校准分数显示 /100 并注明性质；只有有来源的样本外校准概率按概率展示 |
| 时点准确性 | 历史评估使用之后写入的收益/新闻；旧盘中报价确认结构 | 限制成熟交易日窗口、写入时间和资讯截止；盘中报价必须新鲜，历史盘中没有时刻证据就不伪造评估 |
| 持仓动作 | 可卖 0 回退为全部可卖，旧告警覆盖当前判断 | 保留 T+1 和真实可卖数，当前有效判断决定动作；过期证据不能重新授权退出 |
| 页面闭环 | 个股跳外部后研究对象丢失，AI 没有接续对象 | 系统内详情保留股票对象，问答接续可编辑草稿；明确区分模型观点与市场事实，不自动发问 |
| 交互可信度 | 切日期、切股票和连续刷新产生旧响应覆盖 | 为工作台、个股详情和策略跟踪加请求身份；日期写入链接；离开页面停止更新，旧请求不覆盖当前对象 |
| 错误体验 | 请求失败冒充空仓、无风险、空榜单 | 加载、失败、无记录和真实零分开；首页可以单独重试失败证据，其他面板继续可读 |
| 登录与入口 | 登录返回地址可被反斜杠解析为外站；雷达双入口能力不一 | 使用同源 URL 解析验证返回地址；雷达归于同一主系统入口；监控只有一套渲染实现 |

首页的“下一步”是研究导航，不会因为某个分数自动下单。图上的此后指数变化用于核对原始判断，不等于策略收益或预测胜率。

## 反复复查中追加的修复

交叉审查再次复现并修复了：未来市场快照隔离不完整、自选报价字段读取错误、盘前时钟导致盘中不自动更新、策略候选随行情更新不完整、周末复盘被当作不可读当前决策、取消刷新后仍发旧请求、日期与 URL 不同步、空证券码生成入口，以及归档缺报价产生虚假亏损。相关回归实际执行 JavaScript 行为，不只检查页面文案。

后续复查还修复了三个判断残留：推荐尚新时旧分析的高风险评级仍能触发卖出；归档摘要虽标未知，风险预算仍以成本冒充当前市值；总体模拟统计被循环中的最后一项策略覆盖。风险预算 GET 的隐式写入已移除，正式预算仍由既有模拟引擎 tick 生成，查看页面不会重新写预算。

热榜补齐日期和请求身份校验、来源异常与空榜区分、真实可用来源数，以及只读的“当前自选 / 所选日策略关联”。关联信息不参与热度排序；写入自选复用个股详情这一既有入口，打开热榜不会自动写入或触发强制抓取。

移动布局增加了窄屏换行、表格横向滚动、导航收起、键盘焦点和减少动画设置。浏览器连接失败，不能据此声称已完成真实屏宽的视觉验收。
