# 分钟数据采集复用

采集目标以数据类型、交易日、有效股票目录和分钟粒度为单位。已完整的交易日直接复用，保留真实来源；多日请求只采集未完整的日期。

Windows 的股票分钟、分钟资金流和历史缺口修复入口，与 Linux 公共源分钟入口共用 `server/common/minute_acquisition_reuse.py` 的检查。

完整性要求：正式股票目录全部覆盖，停牌例外有独立原生日线证明；逐股票核对唯一分钟、必要字段、来源和完整时间网格。公共源的 240 分钟及 QMT 的 241 分钟分别按真实来源验证，不补造 09:30 行。公共源未提供的均价仍为空，QMT 均价必须有效。分钟资金流同时检查非零股票比例，防止无权限时的全零响应被当作完整数据。

检查只读数据库，按股票和时间索引分批查询。结果记录逐日内容哈希、目录、停牌证明和真实来源。调度器绑定任务参数、版本、运行编号、目标交易日和时间窗口，并重新读库核验。完整复用结果明确记录零上游请求、零写入。

复用证明只表示采集已完整，不产生 QMT 原生认证，也不取得策略发布权限。下游需要的原生证明仍由原有门禁独立校验。

发布范围为跨端：Windows 采集入口、Linux 公共源入口和共享调度验证同时采用合并后的同一 main 版本；不涉及数据库结构变更。
