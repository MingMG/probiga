# 长窗口回放数据补全任务

前置覆盖预查截至 2026-11-20。2024-11-21 至 2026-11-20 有 485 个交易日，其中 48 天有同日行业回执，24 天有同日财务封存回执，两项同时具备的日期为 16 天。公告、日线行情和日内特征的时点覆盖仍待核验。当前业务瓶颈是历史时点数据覆盖。

| 后续工作 | 验收标准 |
| --- | --- |
| 补历史申万一级行业快照 | 按交易日及证券身份核验行业映射、快照公开与接收时间。按板块披露缺口，涵盖北交所和当日仍上市的退市样本。缺少历史证据的行业明确标记未知。 |
| 补财务公告和封存回执 | 区分报告期、公告公开、系统接收和策略可用时间。按决策截点验证签名及逐日逐券覆盖，截点后发布或封存的数据按实际可用时间纳入。 |
| 核验历史公告与行情时点 | 公告区分合法空窗口与失败。行情核验真实收盘、成交量、停牌和公司行动，逐日读回行情及必要特征的可用时间和覆盖。 |
| 登记样本外研究计划 | 冻结版本、费用制度、历史证券池及数据身份，按时间划分训练、调参和样本外区间。报告逐段覆盖、退市样本影响和对账结果。 |

验收使用同一交易日目录和逐日缺口明细，附版本、覆盖数与证据位置。任务负责人和预计完成日期在下一阶段排期确认。
