## 本次必须验收的产品契约

### 动态策略、生命周期与理由

策略和组合数量不得固定，也不得以当前目录或初始清单作为上限。新策略、新组合和实质变化后的新版本可随时通过版本化注册流程加入；已存在版本不可覆盖，新版本必须从影子观察重新积累证据。

页面只展示中文生命周期，英文值仅作为内部稳定枚举：

| 内部枚举 | 页面名称 | 资金含义 |
|---|---|---|
| `ACTIVE` | 正常运行 | 全部门槛通过后才可参与模拟资金竞争 |
| `REDUCE` | 降权运行 | 保留资格但按状态倍率降权，折减部分留在现金 |
| `SHADOW` | 影子观察 | 只积累前向证据，不取得模拟资金 |
| `SUSPENDED` | 暂停使用 | 停止授资；恢复只能先返回影子观察 |
| `RETIRED` | 已淘汰 | 当前版本终态；只能注册新版本重新验证 |

新增、升级、降权、暂停、恢复、淘汰和失败阻断都必须显示具体中文理由，并绑定前后状态、精确版本、目标交易日、证据哈希和决定哈希。排名和健康分不能覆盖生命周期或盈利硬门槛。

### 票池、策略榜和组合榜

同一份 canonical governance 快照必须同时提供：

- 观察池、等待确认池、模拟可交易池；
- 单策略成交实证榜；
- 单策略客户端声明信号研究榜；
- 组合策略榜及成员袖套、行业/股票重合和集中度证据；
- 模拟资金分配、现金余额和不授资理由。

策略榜与组合榜是不同赛道，不得把不可比的原始分数混为一个总榜。客户端声明信号榜的来源没有与权威行情逐行认证，只用于研究和版本选择；观察池、等待确认池或排名靠前都不等于可授资。模拟可交易池允许为空，系统不得为满足数量或仓位利用率强行选票。

### v7 资金统计语义

外部 Walk-Forward 的用途固定为 `VERSION_SELECTION_ONLY` 和 `CLIENT_DECLARED_UNATTESTED`。双人复核只证明提交内容的结构、时序与哈希可重算，不证明客户端收益来自权威数据，也不能提供资金收益、实际费用、组合回撤或模拟资金资格；缺少外部声明不阻断一份已通过全部内部资金门的版本。

只有 `strategy-governance-decision.v7` 具有当前模拟资金语义。每个策略和组合必须基于内部资本加权日频 NAV，并同时满足：

- 按时间顺序切成 5 个互不重叠的内部 NAV 段，至少 4 段日均净收益严格为正；
- 20/60/120 日窗口分别满足最小 ESS 10/30/60；
- 对日频净收益使用 HAC/Newey-West 相关性稳健估计，以单侧 95% 置信下界判断净期望、利润因子和盈亏比；
- 在服务端固定的策略与组合、20/60/120 日、当前与历史/淘汰/失败/挑战者完整检验族上执行 Benjamini-Yekutieli FDR，`q=0.05`，缺失检验按 `p=1`；
- 3 次相互独立的确认通过，相邻确认至少间隔 `max(最大持有期, 标签期限, 5)` 个权威交易日；
- 经济门槛、真实成本压力、回撤、数据时点、执行真实性、市场路由和组合约束全部通过。

v6 及更早决定只能用于历史展示，不能授资。任何一项缺失、无法复算或哈希不一致都必须失败关闭并保留现金。
