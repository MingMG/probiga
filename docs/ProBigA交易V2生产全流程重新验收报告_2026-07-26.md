## 九、未通过项

### P0-001：公网管理鉴权未启用

生产 `/api/health/security` 返回：

```text
status=warn
admin_auth.enabled=false
token_configured=true
ready=false
```

无管理员令牌时：

- `GET /api/scheduler/tasks` 返回200；
- `POST /api/portfolio/refresh-prices` 返回200并实际进入后台队列。

影响：任何能访问公网地址的人都可能读取管理信息或触发写操作。普通行情读取不受影响，但公网管理操作不能放行。

### P0-002：趋势失效后的T+1退出状态迁移异常

生产代码真实执行结果：

```text
ValueError: illegal position transition: VALID -> EXIT_PENDING_T1
```

触发条件：

1. 当前持仓状态为 `VALID`；
2. 趋势或策略失效；
3. 当天因T+1不能卖。

正确行为应是形成不可撤销退出承诺并进入 `EXIT_PENDING_T1`，下一可卖时点继续卖出。当前行为会抛异常，阻断该持仓监控批次。

影响：直接影响用户要求的“趋势破了及时跑”。

### P1-003：数据库真实交易硬约束没有实际落地

代码迁移声明了：

```sql
CHECK (real_trading_enabled = 0)
```

但生产 `SHOW CREATE TABLE st_trade_account_v2` 中没有该约束。当前仍有以下保护：

- 账户值 `real_trading_enabled=0`；
- 账户配置程序每次强制写0；
- 撮合执行器运行时拒绝真实交易；
- 页面和API固定显示真实交易关闭。

但是此前所称的“数据库、运行时、API三层关闭”并不完全属实，目前缺少数据库硬约束这一层。

### P1-004：ETF前向自动任务未部署

生产现状：

- `st_etf_forward_strategy`：0条；
- `st_etf_forward_observation`：0条；
- 生产调度器中没有ETF前向任务；
- ETF策略注册状态为 `SHADOW`，配置要求从2026-07-27开始且禁止回填。

观察记录为0在2026-07-26是正确的，但没有调度任务意味着2026-07-27也不会自动产生真实前向记录。

### P2-005：失败回测遗留孤儿RUNNING记录

生产存在：
