# 概念、行业热力图盘中可见性

目标：市场看板在交易时段按分钟显示当日概念、行业行情与资金流，标出来源时间；5日窗口使用前4日及当日盘中值。

已观察根因：`build_sector_heatmap` 在当天15:00前直接返回空值；原有日级行业任务默认17:08采集。页面原有60秒刷新无法突破接口拦截。生产基线为 e242e14a099351dcf79e25c192825e3751233a33。

源端只读检查：2026-11-19晚，生产网络的东财批量接口声明概念554、原生行业496，样本具备f124来源时间、价格及f62/f66/f72资金分量。完整分页、持久化及线上版本的验收在部署后执行并留在本次聊天记录中。

实现：Linux API按页面需求抓取有界分页批次，固定按代码排序，核验总量、唯一身份、日期与时间。两个板块源独立更新；私有SQLite保存校验摘要及持久读回，45秒内复用。每次源端请求至多3秒、无内部重试，整批10秒截止；每分钟由已有看板轮询触发下一次有界尝试。历史日仍使用正式日级数据，盘中快照不写成日级完成记录。交易中超过180秒的数据不进入排名，午休按11:30计算时效。资金分量不符时不提供该项排名。

范围：LINUX。`server/api/routers/market_home.py`、`server/common/sector_live.py` 与静态资产；不改共享schema、任务所有权、QMT协议或Windows配置。复用原有发布broker的Linux切换和回滚事务。

验证：48项相关API及页面测试通过。覆盖当天10:30盘中显示、前4日加盘中5日窗口、资金分量、持久快照复用、源失败隔离、午休与陈旧源，以及历史日隔离。当前真实时间已收盘，交易时段自然自动刷新只能在后续实际发生后确认。
