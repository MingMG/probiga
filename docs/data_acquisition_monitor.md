# 数据获取监控

入口为侧栏“数据获取监控”。每列一个自然日，每行一种数据，默认近 30 天，可选近 90 天、今年或至多 366 天的范围。

绿色表示当日应采集合及关键字段全部核验通过；黄色表示部分缺失或异常；红色表示已到期但没有数据；灰色表示交易日历明确休市；空心表示尚未到完成时限；紫色表示应采范围、源回执或实际查询尚不能确认。日历无记录不按周末规则猜测。蓝色外圈只表示有目标日期和新鲜调度器心跳支持的运行任务；补数队列 RETRYING 不等于正在运行。

点击日期查看应有、有效、缺失记录数、检查时间、数据更新时间、股票及缺失时段、补数队列和执行记录。详情显示前 200 项，CSV 保留该次检查的完整缺口及检查时间；导出不额外启动数据库扫描。任务没有可验证分母时，不编造进度百分比。

## 核验依据

- 股票日线：独立历史股票目录及合法无行豁免，检查不复权日线的身份、重复和 OHLC 字段。
- 股票分钟线：已核验日线的有成交集合，每只股票原生 QMT 241 个分钟时点；重复、无效记录及非交易时段不能填充缺口。
- 每日资金流：有成交股票应到齐；独立当日范围内停牌股票的可选记录不当作超范围数据。
- 分钟资金流：同一交易集合和原生 241 点，不将盘中抽样数据当成完整分钟历史。
- 龙虎榜：源回执和当前库内容一致才完整，合法零条也需要完整源回执。
- 指数、东财概念、人气榜：验证历史源回执、目录及当前分区内容；仅有任务成功或旧覆盖率 PASS 不能变绿。跨日期指数回执暂不能证明单日独立完整性时显示待核实。

完成时限为北京时间：分钟线 15:35，人气榜 17:14，日线及其他日数据 18:00，分钟资金流次日 00:00。时限前显示未到期。

## 负载与刷新

`GET /api/datasource/monitor`、`/detail`、`/gaps.csv` 使用现有 API 鉴权，响应禁止浏览器缓存。每个 API 进程只有一个后台核验线程，先检查最近日期，详情可优先排队，队列至多 366 天、缓存至多 400 天。分钟聚合按现有股票索引分批执行；服务关闭时取消排队并在数据库读取边界停止。未核验、过期或失败的结果显示待核实，不保留旧绿色。完整源回执缺失会导致待核实，需要恢复真实证据而非降低完整标准。

页面可见时每 30 秒读取状态；核验缓存最多 30 分钟，可逐日复检。大范围首次核验可能需要较长时间，界面显示已检查和排队天数。本地远程数据库抽查一个完整交易日九类数据约 47 秒，耗时取决于库负载与网络，不是性能保证。
