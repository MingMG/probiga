# 历史行情采集与完整分区复用

日线复用只回放完成凭证声明的 `gj_big_qmt_inner` 原生分区，并继续核对精确股票集合、记录数、质量状态和权限状态。相同交易日其他来源的历史行保留，不混入该原生凭证。凭证要求的股票被覆盖为其他来源时仍须失败，不能缩小目标集合冒充完整。

2026-07-13 的现有日线包含 5,523 条有完成凭证的 QMT 行及 78 条来源为空的旧行。把全部 5,601 行套入原生凭证会误报分区不一致；正确复用无需再次下载，也无需删除旧行。

分钟采集引用已验证的原生日线无交易证明时，日线事实保留自己的不可变股票目录和交易日历根。分钟采集可以使用后来发布的目录和日历，两组权威记录分别从数据库回放。日线证明内部的根、日期、提供方和证明哈希仍须一致，采集时点不得变造，实际日线或分钟记录与无交易证明冲突时仍阻断。

分钟子进程的覆盖校验失败以结构化 `DATA_BLOCKED` 和退出码 3 返回。父进程沿用现有分类规则，不把数据完整性问题误判为登录失效；连接故障继续走终端恢复路径。

影响范围为 Windows 行情采集及两端共享的覆盖凭证验证，按跨端部署。无数据库结构、桥接协议或任务归属变更。历史分区只有在原生采集、正式入库及独立读库校验完成后才算修复，不能直接改缺口台账为成功。
