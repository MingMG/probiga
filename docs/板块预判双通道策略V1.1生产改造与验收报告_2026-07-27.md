## 1. 结论先说

旧策略不是完全看不到创新药和电力，而是早期线索在四层规则中被删除：

1. 板块必须一次性满足全部硬阈值，弱转强和首日点火容易被判为不合格或过热；
2. 每天重新计算，没有把连续两三天的板块强度当作状态保存；
3. 相近概念先做成员去重，创新药、电力改革等细分方向会被更大的医药或公用事业标签覆盖；
4. 预判观察股和正式执行股共用名额，后台即使算到了，最终页面也可能没有对应个股。

V1.1 改成两条相互隔离的通道：

- 正式执行通道：保留 V1.0 冻结条件、12 只候选上限、组合竞争和风控，不降低原有买入标准；
- 预判观察通道：识别首日点火、弱转强和连续增强，独立保留最多 120 只去重后的观察股；信号方向强制为 `HOLD`，不参与组合抢位，不创建订单。

因此，本次改造解决的是“机会完全看不见”的问题，而不是把未经验证的线索包装成必买信号。

## 2. 当前完整选股流程

```text
QMT 行业/概念成员 + QMT 日K
              │
              ▼
市场状态：积极 / 轮动 / 震荡 / 恐慌修复 / 防守 / 极端风险
              │
              ▼
板块证据：上涨宽度、站上MA5、相对强度、成交额、宽度加速、动量加速、连续性
              │
       ┌──────┴──────┐
       ▼             ▼
预判观察通道       正式执行通道
首日点火           原冻结严格确认
弱转强             原热点去重
连续增强           原候选与风控
       │             │
       ▼             ▼
HOLD/WATCH         READY 才能竞争
不占仓、不下单      最多4个模拟仓位
       └──────┬──────┘
              ▼
盘中确认、T+1、涨跌停、流动性、动态退出、日终对账
```

正式通道还必须通过个股条件：非 ST、非临近涨停追板、成交额足够、量能确认、站上 MA5、短期涨幅不过度延伸、次日价格不超过不追高价、盈亏比满足冻结要求。

持仓不再按固定天数死拿。趋势、板块或市场状态破坏时退出；若受 T+1 或流动性限制，则进入待退出状态。趋势仍强时允许继续持有，到复核点再判断，而不是到期机械卖出。

## 9. 研究依据

- Moskowitz 与 Grinblatt 的行业动量研究表明，个股动量中有相当部分由行业动量驱动，因此系统需要先识别板块，再选择个股：<https://onlinelibrary.wiley.com/doi/pdf/10.1111/0022-1082.00146>
- Moskowitz、Ooi 与 Pedersen 的时间序列动量研究支持趋势具有持续性但随后可能反转，因此退出不能只用固定持有天数：<https://w4.stern.nyu.edu/facdir/lpederse/papers/TimeSeriesMomentum.pdf>
- Moreira 与 Muir 的波动率管理研究支持在波动升高时降低风险暴露，而不是在极端市场中机械满仓：<https://www.nber.org/papers/w22208>
