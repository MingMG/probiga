# 超级马里奥 · 像素冒险

非官方同人网页小游戏。独立于父项目服务，静态部署，无数据库与外部 API。

## 游玩

Enter 开始；方向键或 A/D 移动；Space、W、↑ 或 Z 跳跃；Shift 或 X 加速；P/Esc 暂停；R 重开；M 静音。手机使用画面下方的多点触控按钮。

一关完整地上世界：问号砖、金币、蘑菇变大、可破坏砖块、踩敌人、受伤无敌、三条生命、限时、终点滑旗、城堡和计时奖励。音效与短原创芯片音乐由 Web Audio 合成，像素素材为本项目绘制，不加载外部素材。

## 开发与验证

```sh
npm ci
npm run dev -- --port 4317
npm test
npx tsc --noEmit
npm run build
```

构建输出 `dist/client`，Sites 配置位于 `.openai/hosting.json`。Windows 构建预加载脚本允许成功构建自然退出，避免原生构建器关闭时与 CLI 强制退出产生竞争；非零退出码仍正常保留。

核心物理以固定 60 Hz 步长运行。测试覆盖长短跳、移动与惯性、高管道可达性、砖块与道具、双敌人踩踏、暂停、死亡重生、计时与通关。

支持浏览器时注册 `read_game_state` 和 `control_game_session` WebMCP 工具。当前环境无受支持的 WebMCP 验证上下文，未进行该可选功能的真实上下文验证。未执行浏览器交互或视觉 QA。

## 发布

遵循仓库 `AGENTS.md`：从最新 main 新建独立分支，在分支验证并提交，推送后合并 main，再从合并版本提取本目录推送至 Sites 源代码仓库。仅发布本小游戏的静态输出。
