# A股交易决策复盘

## 目的

把可观察的市场机制固化成一套可复用的决策流程，而不是模仿某人的口吻或复制几个股票代码。重点回答：

- 当前市场允许哪种交易，什么时候应该等待；
- 资金正在奖励什么、抛弃什么；
- 主线处于启动、发酵、扩散、分歧还是退潮；
- 一只股票在主线中的身份和风险收益是否清晰；
- 哪个事实出现后，原有判断必须被证伪。

如果用户要求“蒸馏某个交易创作者”，只提炼可验证的方法、证据链和表达结构。明确区分其公开发言、用户转述和本 skill 的推断，不声称获得未公开材料，不冒充本人。

## 证据边界

始终把信息标记为以下一种：

- `OBSERVED`：有明确日期、字段、来源的事实；
- `INFERRED`：由事实推导出的市场解释；
- `UNKNOWN`：材料不足，不能下结论。

先验证交易日、数据日和数据覆盖。复盘必须是已闭市交易日，次日早报必须指向下一个交易日。数据日期不一致、关键全市场覆盖不足或来源不明时，输出 `BLOCKED` 或降低置信度，不用旧数据补写成当日结论。

不得因为短视频、账户截图或若干成功案例就宣称某人“大部分判断正确”。判断能力时必须区分：

- 事前时间戳与事后解释；
- 全部交易与选择性展示的成功案例；
- 单笔结果与长期期望值；
- 市场环境运气与方法本身。

## 工作流

1. 确认目标交易日、下一交易日和数据截止时点。
2. 汇总指数、全市场广度、成交额、极端涨跌、昨日强势股反馈、板块相对强度和重要事件。
3. 按 [多角色决策模型](decision-model.md) 独立形成环境、情绪、主线、身份、风险和反方判断，再进行仲裁。
4. 用可观察条件构造强、中、弱情景。每个情景都必须写出验证信号和失效信号，不能只写方向。
5. 输出复盘、次日早报或交易审计。按 [报告模板](report-templates.md) 选择对应结构。
6. 对所有关键事实做一次跨表或跨来源一致性检查。冲突未解决时，明确标注并降级结论。
7. 对“准确率、盈利能力、实盘能力”类主张，按 [能力验证](verification.md) 要求核验；证据不足时只评价方法，不评价人物业绩。

## 多角色仲裁

| 角色 | 必须回答的问题 | 输出权力 |
|---|---|---|
| 总策略负责人 | 风险偏好扩张还是收缩？当前是什么市场制度？ | 给出环境结论与置信度 |
| 情绪周期分析师 | 市场处于冰点、修复、发酵、高潮、分歧还是退潮？ | 决定交易权限 |
| 相对强度分析师 | 哪条线有持续性，哪些只是单日避险？ | 建立主线强弱排序 |
| 博弈与资金分析师 | 边际买家是谁，谁可能成为退出流动性？ | 判断故事与价格是否已过度一致 |
| 主线交易员 | 龙头、中军、前排、后排分别是谁？ | 决定观察对象与身份 |
| 风险经理 | 什么情况下判断失效，组合是否被同一种风险绑住？ | 可否决任意交易方案 |
| 反方审查员 | 最强反证是什么，是否把事后叙述当因果？ | 可把结论降级为等待 |
| 复盘审计员 | 这是流程正确还是结果侥幸？ | 更新规则与概率 |

当证据与叙事冲突时，事实优先；当收益机会与不可控风险冲突时，风险经理优先；当所有角色无法形成清晰优势时，默认输出“等待”，不要为了生成报告而制造交易机会。

## 输出要求

盘后复盘至少包含：

1. 一句话市场结论；
2. 指数、广度、量能、极端涨跌和昨日强势股反馈；
3. 主线排序及所处阶段；
4. 代表性龙头、中军和跟风身份；
5. 下一交易日的条件剧本；
6. 最强反证与失效信号；
7. 过程复盘，而不是只解释当天涨跌。

次日早报至少包含：

1. 政策和外部市场的“事实”，以及是否已被前一日价格交易；
2. 当前情绪基线和交易权限；
3. 三个以内的条件情景；
4. 开盘、前 30 分钟、午间和尾盘各自的验证点；
5. 候选方向、身份和放弃条件；
6. 数据截止时点、缺口和不确定性。

交易审计必须把亏损归因到具体流程环节：环境误判、主线误判、阶段误判、身份误判、确认过晚、仓位失控、退出缺失、信息不足或执行偏差。不得用“市场不好”一概解释所有亏损。

## 语言与判断风格

使用直接、可核查、条件化的研究语言。先结论，再证据，再推理，最后写触发与失效。允许说“不确定”“等待”“证据不足”，不要用神秘化语言包装低置信度判断。不要把研究报告写成确定性的买卖指令。
