# 能力验证

## 先区分四件事

1. 方法是否说得通；
2. 单次判断是否兑现；
3. 完整交易系统是否有正期望；
4. 某个创作者是否真的长期盈利。

前者不能自动证明后者。视频、截图、粉丝数、关注数和点赞数都不是账户业绩证明。

## 判断“判断很准”的最低证据

- 判断发布时间早于结果；
- 记录全部样本，而非只展示成功案例；
- 明确观察周期和收益口径；
- 包含失败和放弃的案例；
- 给出实际进入、退出和仓位规则；
- 包含交易成本和滑点；
- 与同期市场基准比较；
- 样本覆盖不同市场环境；
- 至少有一定数量的独立交易样本。

只有条件语言、多个分支和事后解释时，不能认定高准确率。多情景预案是有价值的风险管理，但不能把所有结果都宣称为成功预测。

## 交易系统的核心指标

至少计算：

- 胜率；
- 平均盈利与平均亏损；
- 盈亏比；
- 期望值；
- 最大单笔亏损；
- 最大回撤及恢复时间；
- 暴露时间和空仓比例；
- 换手率与成本；
- 不同市场制度下的分组表现；
- 样本外表现。

可用近似关系：

```text
期望值 = 胜率 × 平均盈利 - 败率 × 平均亏损 - 成本
```

胜率高不等于赚钱，胜率低也不等于系统无效。尾部亏损和风险暴露经常比胜率更重要。

## 识别幸存者偏差

以下材料不足以证明长期能力：

- 只展示盈利截图的短视频；
- 删除失败内容的账号；
- 事后挑选顶部和底部；
- 非固定资金曲线的收益展示；
- 没有完整交易记录的口头总结；
- 在不同市场阶段切换口径的准确率统计；
- “长期看对”但无法给出短期失效规则的说法。

评价时必须明确资料边界。资料不足时，可以评价方法论、证据链和逻辑一致性，但不要评价真实盈利能力。

## 防止叙事替代交易

一个正确判断至少要通过四层验证：

1. 事实层：信息真实且时间可用；
2. 因果层：逻辑能够解释资金为何现在行动；
3. 价格层：市场已用成交和相对强度确认；
4. 执行层：有可承受的失效点和退出流动性。

只有基本面或新闻逻辑时，最多称为研究观点，不能称为完整交易方案。

## 审计用户自身的亏损

把每笔亏损归到以下一个或多个环节：

| 环节 | 典型证据 |
|---|---|
| 环境 | 普跌、强势股负反馈、成交衰竭时仍积极交易 |
| 情绪阶段 | 高潮或退潮期继续追逐扩散 |
| 主线 | 把单日异动或防守抱团误判为持续主线 |
| 身份 | 买后排却按龙头预期持有 |
| 触发 | 消息出现前抢跑，或价格确认后追高 |
| 仓位 | 单次风险超过可恢复范围 |
| 集中度 | 多个持仓实际押注同一因子 |
| 退出 | 预设失效点未执行 |
| 数据 | 使用过期、错日期或覆盖不足的数据 |
| 执行 | 滑点、流动性、情绪化操作 |

不要只用“看错了”解释亏损。必须定位到第一个可复现的决策错误，再给出下一次的检查规则。

## 方法升级规则

- 一个成功案例不足以证明新规则；
- 一个失败案例也不足以删除长期有效规则；
- 只有在重复出现、可由数据解释且改进能降低预期损失时，才修改规则；
- 保留修改前后样本，做样本外或滚动验证；
- 新规则必须明确适用的市场环境，防止因一次行情过拟合。
