# 多角色决策模型

## 总体决策函数

不要先问“哪只股票会涨”，先解这个带约束的问题：

> 在可承受的最大错误成本、流动性和确认条件下，哪个方向具有最高的条件期望值？

核心变量：

```text
市场状态 M
× 情绪阶段 E
× 主线状态 S
× 个股身份 R
× 触发质量 T
÷ 失效风险 X
```

这不是精确公式。它表达的是：环境差、阶段高、身份弱、触发差或失效成本大时，任何单一利好都不足以构成交易理由。

## 角色一：总策略负责人

目标：先判断当前市场是否允许承担风险。

读取：

- 主要指数涨跌、收盘相对日内高低点；
- 两市成交额及相对前一交易日变化；
- 上涨/下跌/平盘家数和全市场平均涨跌幅；
- 极端上涨和极端下跌家数；
- 昨日强势股今日平均反馈；
- 北向、两融、主力资金等可用增量信息；
- 政策和外部市场事件的时效性。

分类：

- `进攻`：广度改善、强势股有正反馈、主线明确扩散；
- `轮动`：指数震荡或分化，有局部强势方向，但持续性有限；
- `防守`：普跌、强势股负反馈、资金转向防守；
- `风险释放`：放量下跌、极端下跌扩张、收盘接近低位；
- `修复待确认`：极端下跌收缩、上涨家数改善，但主线仍不清晰。

要求：指数上涨不等于赚钱效应改善。必须同时检查广度和强势股反馈。

## 角色二：情绪周期分析师

目标：确定市场处于什么阶段，以及现在应该试验、持有、兑现还是等待。

阶段：

1. `冰点`：亏钱效应充分，但新周期尚未确认；
2. `修复`：修复广度增加，昨日强势股开始减亏；
3. `发酵`：主线形成，龙头和中军得到正反馈；
4. `高潮`：扩散广泛、后排补涨、信息高度一致；
5. `分歧`：龙头波动加大，后排开始掉队；
6. `退潮`：反抽失败、高位补跌、流动性收缩；
7. `再冰点`：极端亏钱效应出现，等待下一轮修复。

不得只用单个“情绪分数”判断。至少结合：

- 极端上涨和极端下跌的净差；
- 连板高度与其反馈；
- 炸板或触板后回落情况；
- 昨日强势股今日表现；
- 主线宽度和后排存活率；
- 成交额是否支持当前扩散程度。

固定家数阈值只在同一数据口径下使用。跨板块、跨年份比较时，用相对变化、分位数和昨日反馈，避免把某天的固定数字当成永久标准。

## 角色三：相对强度分析师

目标：区分“新主线”“防守抱团”“旧题材反抽”和“单日异动”。

对每个候选方向检查：

- 催化是否新，是否仍有增量信息；
- 连续几天的相对强度；
- 龙头、中军、前排与后排是否形成正反馈；
- 资金流入是否伴随价格和成交；
- 分歧后是否有回流；
- 强度来自行业逻辑、指数权重护盘，还是短线避险。

主线成立至少需要：

1. 催化仍有交易价值；
2. 板块中有多个层级共同响应；
3. 龙头上涨能带动同板块，而非孤立上涨；
4. 分歧后仍有承接。

只有防守股逆势上涨、后排持续下跌时，优先定义为“防守抱团”或“缩圈”，不要直接升级为新主升。

## 角色四：博弈与资金分析师

目标：识别边际买家、边际卖家和退出流动性。

连续追问：

1. 现在买入的人是在获得新信息，还是因为价格已经上涨？
2. 谁掌握了更早的成本，谁需要借当前成交量退出？
3. 利好后价格没有上涨，说明什么？
4. 利空后价格没有继续下跌，说明什么？
5. 当前逻辑是否已经成为广泛共识？
6. 若明天出现不利信号，成交是否足以让使用者安全退出？

短期市场的常见反馈链：

```text
新信息
→ 先手资金试错
→ 龙头价格确认
→ 媒体和社交传播
→ 增量资金扩散
→ 后排补涨
→ 分歧与兑现
→ 反抽失败
→ 高位补跌
```

越靠近“媒体传播—后排补涨”阶段，赔率越差。反身性逻辑的要点不是预测终值，而是判断正反馈是否仍在、何时开始断裂。

## 角色五：主线交易员

目标：把方向转换成可执行的身份，而不是一个模糊的板块名称。

身份：

- `龙头`：决定板块情绪高度，拥有最强定价权；
- `中军`：成交额和容量较大，反映趋势资金是否参与；
- `前排`：紧随龙头，弹性较高但依赖龙头；
- `后排补涨`：通常在扩散高潮阶段出现，退潮时流动性最差；
- `容量核心`：承接大资金，适合判断板块是否仍有增量；
- `纯情绪票`：缺少基本面承接，失效速度快。

每只观察对象必须写出：

- 在主线中的身份；
- 预期由谁推动；
- 需要什么价格和成交确认；
- 若身份被市场否定，哪些事实会出现；
- 与同组股票的相关性和替代关系。

没有清晰身份和触发条件时，不生成个股方案，只生成观察条件。

## 角色六：风险经理

目标：确保判断错误时仍然可恢复。

至少检查：

- 单笔判断失效的具体价格或盘面事实；
- 最坏情况是否会破坏账户恢复能力；
- 多个持仓是否实际押注同一个风险因子；
- 流动性是否支持退出；
- 事件窗口是否使隔夜风险不可控；
- 方案是否依赖开盘必须按预期运行。

仓位管理优先于方向表达。不要用一个确定的止损数字伪装低风险，也不要因为逻辑“长期正确”就忽视短期价格失效。

若组合高度集中在同一主线、同一风格或同一高波动方向，应提示这是“一个风险”而不是“多个机会”。

## 角色七：反方审查员

目标：主动寻找最强反证。

必须回答：

1. 如果当前结论是错的，最可能错在哪里？
2. 哪个数据矛盾被解释掉了？
3. 这是新增资金，还是存量资金从一个方向搬到另一个方向？
4. 这个结论是否只能事后验证，无法事前执行？
5. 是否把政策意图、媒体叙事或单日价格误当成持续资金？
6. 当前成功是否是特定市场制度下才有效？
7. 结论能否被一个明确事实低成本证伪？

如果无法构造可证伪条件，结论不合格。

## 角色八：复盘审计员

目标：把当天交易结果转化为概率更新。

复盘四问：

- 原假设是什么？
- 哪些证据支持或否定了假设？
- 如果重来一次，哪个时点应买、卖、等或放弃？
- 结果来自流程正确，还是随机性？

不得因为赚钱就强化错误行为，也不得因为一次正确流程亏钱就否定系统。至少记录：

- 事前判断与时间；
- 实际触发；
- 进入与退出逻辑；
- 最大有利波动和最大不利波动；
- 计划风险与实际风险；
- 结果与同期基准；
- 可复现的流程错误。

## 次日情景构造

每个剧本必须包含：

| 项目 | 要求 |
|---|---|
| 前提 | 当前市场基线和关键变量 |
| 验证 | 开盘、前30分钟、午后或尾盘的可观察事实 |
| 行为 | 在该条件下允许观察什么、放弃什么 |
| 失效 | 哪个事实出现即不再使用该剧本 |
| 反证 | 最可能推翻它的证据 |

先写证据触发，再写操作。不要先写“明天看涨/看跌”，再寻找支持理由。

## 期望值与错误分布

长期结果近似取决于：

```text
胜率 × 平均盈利
- 败率 × 平均亏损
- 交易成本
```

低胜率仍可能长期盈利，高胜率也可能因一次大亏而失败。分析交易方法时，必须同时看胜率、平均盈亏比、最大回撤、尾部损失、暴露时间和市场环境分布。

## 典型误学

- 把结论当交易计划，忽略时间、位置、仓位和退出；
- 把新闻逻辑正确当成价格会上涨；
- 把龙头缩圈当成全面扩散；
- 把防守抱团当成新主升；
- 在情绪高潮时用“长期逻辑”解释短线风险；
- 把多个相关持仓误认为分散；
- 只复盘结果，不复盘决策时的信息集；
- 用少数成功视频替代完整交易样本。
