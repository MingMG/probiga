# 已对接数据同步：命令 + 注释说明

以下均在 **仓库根目录**（`ProBigA`）执行；需配置 **`MYSQL_URL`**，并已安装依赖：`pip install -e ./adata`、`pip install -r requirements-platform.txt`。

**复制执行时**：只复制「命令」那一行；下面「说明」仅供阅读。

---

## 一、`run_single_table.py`（按表名触发，推荐）

**说明（本节共性）**：`si_*` 在进程内调 STOCK-INFO；`sm_*` / `st_*` 会子进程执行对应 `biz.*.sync_*`，并自动设置 `PYTHONPATH` 等。多数步骤会先 **TRUNCATE** 目标表再写入。

**命令**

`python tools\run_single_table.py si_all_index_code`

**说明**：同步表 **`si_all_index_code`** — 全市场**指数代码列表**（默认新浪；也可走东财，见 `SI_INDEX_PRIMARY` 等）。

**命令**

`python tools\run_single_table.py si_index_constituent`

**说明**：同步表 **`si_index_constituent`** — 各指数的**成分股**（依赖 `si_all_index_code` 非空）。

**命令**

`python tools\run_single_table.py si_concept_constituent_east`

**说明**：同步表 **`si_concept_constituent_east`** — 东方财富**概念板块成分股**（依赖 `si_concept_code_east`，空时会先拉概念列表）。

**命令**

`python tools\run_single_table.py sm_dividend`

**说明**：同步表 **`sm_dividend`** — 全市场（或限流配置下）**分红送转**数据。

**命令**

`python tools\run_single_table.py sm_stock_capital_flow_daily`

**说明**：同步表 **`sm_stock_capital_flow_daily`** — 个股**日级资金流向**。

**命令**

`python tools\run_single_table.py sm_stock_capital_flow_min`

**说明**：同步表 **`sm_stock_capital_flow_min`** — 个股**分时资金流向**。

**命令**

`python tools\run_single_table.py sm_stock_minute`

**说明**：同步表 **`sm_stock_minute`** — 个股**分钟行情**。

**命令**

### 辅助子命令

**命令**

**说明**：打印本工具支持的**全部表名**（HANDLERS 键）。

## 七、环境变量（按需配合上面命令）

| 变量（示例） | 作用简述 |
|--------------|----------|
| `MYSQL_URL` | MySQL 连接串，写入库 **`probiga`**（默认见各模块）。 |
| `SI_INDEX_PRIMARY` / `SI_INDEX_TRY_EAST_FIRST` 等 | 指数列表走**新浪还是东财**、重试与备用线路等（见 `sync_stock_info.py`）。 |
| `SM_MAX_STOCKS` / `SM_MAX_INDEXES` / `SM_MAX_CONCEPTS` | Market 全市场任务**调试上限**；`run_single_table` 子进程里常默认 **`0` 表示不限制**。 |
| `SE_SKIP_GLOBAL_TRUNCATE` | 舆情**不清场**多张表；各步仍会 TRUNCATE **本步目标表**。 |
| `SE_A_LIST_DATE` / `SE_A_LIST_DATE_START` / `SE_A_LIST_DATE_END` | 龙虎榜**单日**或**日表历史区间**；明细批量与 `SE_A_LIST_FROM_DB` 见 `sync_sentiment.py`。 |
| `SE_A_LIST_TRADING_DAYS_ONLY` | 拉日表区间时是否**只按交易日历**遍历（需 **`si_trade_calendar`** 有数据）。 |

**PowerShell 示例**（只演示设库再跑一步）：

```powershell
$env:MYSQL_URL="mysql+pymysql://user:pass@127.0.0.1:3306/probiga?charset=utf8mb4"
python tools\run_single_table.py sm_stock_current
```
